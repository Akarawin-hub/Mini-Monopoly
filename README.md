# Mini Monopoly Core

Implementation of the currently agreed shared core classes:

- `Player`
- `Property`
- `Tile`
- `Board`
- `Dice`
- Shared types: `PropertyTier`, `TileType`, `PlayerStatus`

## Current shared rules used here

- Starting Money: 1,000
- Board: 32 tiles
- Dice: 1–6
- Hold Property: max 5
- Direct Purchase Count: max 7 successful purchases
- Sell Property: 20% of Property price
- Selling a Property clears its Rent Pool
- Board positions use 1–32
